# 家庭维修事项

端口规划：`5114`

```bash
npm install
npm run dev
```

第一版闭环：记录维修问题、按状态查看、更新处理状态、统计未完成预计费用，支持照片链接并使用localStorage保存数据。

计划日期：新增事项可填写计划完成日期；列表显示剩余/逾期天数，逾期未完成事项标红；未完成事项按计划日期从近到远排列，无计划日期排在最后，已完成事项排在列表末尾；日期、排序和状态经 localStorage 持久化，刷新后保持一致。

费用类型与预算：新增事项选择材料费、人工费或其他；统计区可设置本月预算上限，本月已花费按本月完成事项的费用合计（含已归档事项），超出预算时红色高亮并提示超出金额；费用类型、预算与花费刷新后保持一致。预算功能上线前已完成、没有完成日期的旧事项，首次加载时按计划日期（不晚于今天）或当前日期补全完成日期并计入统计，迁移结果持久化到 localStorage。

归档：已完成事项可归档，归档后从默认列表（含各状态筛选）隐藏，工具栏「归档事项」入口可查看数量并进入归档视图，支持恢复或删除；归档状态与当前视图经 localStorage 持久化；未完成统计、预计费用统计、预算提醒和计划日期排序均不受归档影响。

数据备份：侧栏「数据备份」可导出包含全部事项、预算、筛选/视图和归档状态的 JSON 文件（`home-repairs-日期.json`）；导入该文件时会先校验结构（JSON 合法性、必填字段、状态/优先级/费用类型、费用与日期格式、id 唯一），通过后整体恢复并持久化，格式错误则红色提示且不改动现有数据。

## 浏览器回归测试

首次运行需安装 Playwright 浏览器：

```bash
npx playwright install chromium
npm test
```

用例覆盖：新增计划日期与剩余天数、逾期标红与逾期天数、按计划日期排序、刷新持久化，以及状态筛选/删除/费用统计回归。
