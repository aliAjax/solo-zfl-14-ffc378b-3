# 家庭维修事项

端口规划：`5114`

```bash
npm install
npm run dev
```

第一版闭环：记录维修问题、按状态查看、更新处理状态、统计未完成预计费用，支持照片链接并使用localStorage保存数据。

计划日期：新增事项可填写计划完成日期；列表显示剩余/逾期天数，逾期未完成事项标红；未完成事项按计划日期从近到远排列，无计划日期排在最后，已完成事项排在列表末尾；日期、排序和状态经 localStorage 持久化，刷新后保持一致。

费用类型与预算：新增事项选择材料费、人工费或其他；统计区可设置本月预算上限，本月已花费按本月完成事项的费用合计，超出预算时红色高亮并提示超出金额；费用类型、预算与花费刷新后保持一致。预算功能上线前已完成、没有完成日期的旧事项，首次加载时按计划日期（不晚于今天）或当前日期补全完成日期并计入统计，迁移结果持久化到 localStorage。

## 浏览器回归测试

首次运行需安装 Playwright 浏览器：

```bash
npx playwright install chromium
npm test
```

用例覆盖：新增计划日期与剩余天数、逾期标红与逾期天数、按计划日期排序、刷新持久化，以及状态筛选/删除/费用统计回归。
